# Rh_promo

📌 Sobre o Projeto
Este projeto tem como objetivo prever se um funcionário será promovido utilizando técnicas de Machine Learning e Deep Learning, passando por todas as etapas de um projeto de Ciência de Dados.


🎯 Objetivo
Construir modelos capazes de identificar a probabilidade de promoção de colaboradores com base em informações como departamento, idade, escolaridade, avaliações e tempo de serviço.


🛠 Tecnologias
Python, Pandas, NumPy, Matplotlib, Scikit-Learn, TensorFlow/Keras e Google Colab.


⚙ Etapas
Importação dos dados; limpeza e tratamento; análise exploratória; codificação e normalização; treinamento de Random Forest e Rede Neural; avaliação dos modelos.


📈 Resultado
Comparação entre algoritmos de Machine Learning e Deep Learning para classificação binária de promoção.
